# グラフの仕様

| 画面 | グラフ |
| --- | --- |
| 会社・総合 | 日別の実績、事業・ファネル別比較、施策状況 |
| SNS・LP | アカウント別フォロワー、UTAGE 日次記録 |
| 実績の分析 | 指標別推移、軸別・掛け合わせ比較、ファネル段階 |
| OKR | 比較条件を確認した観測に基づく目標進捗、ファネル実績 |
| 実行管理 | 絞り込んだ施策の作業状況・結果判断 |
| SNS 投稿 | 下書きの確認状況・投稿先。実接続対応時の投稿指標 |
| 広告 | 選択アカウントの指標推移・広告別比較・変更状況 |
| Astra | 仕事の状態、呼び出し・ステップ・トークン使用量 |
| 改善・診断 | 案件状態、比較実験、表現別実績、判断・実行履歴 |
| 実績取込 | 検証済みの保存前データの推移・比較 |
| 設定 | 案件の構成、目標指標、観測、接続・実行準備状況 |
| 全体管理 | 利用中・停止中の人数、事業ごとの閲覧可能人数 |

日別の欠落と未取得値を補間しません。0 は有効なデータとして表示します。一部未取得の合計には注記を付けます。観測期間・アカウント・通貨・指標の単位が異なるものを同じ系列へ無条件に合算しません。期間やフィルターを持つ画面では既存の表示範囲に合わせます。

編集・取込のプレビューは未保存と表示します。状況別の件数や準備状況は、業績や外部サービスの現在の稼働を保証する指標ではありません。比較実験のグラフは画面に読み込んだ期間の記録を表し、実験全期間の確定判定とは区別します。

棒と折れ線は画面幅に追従し、正確な値を開ける表と、折れ線上の点へのキーボードフォーカスを備えています。
