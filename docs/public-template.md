# 公開版の構成

ソース、DB のスキーマ、架空値を使う単体テスト、空のフォーマット、導入手順を含みます。

過去の Git 履歴、運用記録、顧客・事業の実績、登録済みユーザー、接続キー、実運用の Cloudflare ID、個人の接続先、ローカル DB、ビルド出力、秘密ファイルを含めず、新しい履歴から作成しています。

`check:template` は配布用の空状態・プレースホルダー・不要ファイルを確認します。実運用に設定済みの派生リポジトリでは、この検査が失敗するのは意図した動作です。秘密情報の完全な検出を保証するツールではないため、公開前には差分と履歴も確認してください。

会社と最初の事業は空の初期構造として作成されます。テスト内の架空の事業・実績は、アプリ起動時には読み込まれません。
